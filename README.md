# 🎮 Board Game Design Engine

An AI-assisted game design laboratory for balancing and testing your board game through simulation and data analysis.

---

## 🚀 Quick Start

**First time here?** Follow these steps:

1. **Read the getting started guide**: `GETTING_STARTED.md`
2. **Explore example cards**: `rules/_examples/`
3. **Read the learning guides**: `docs/` (6 progressive tutorials)

## 🎯 What This Does

✅ Define game rules as structured YAML data

## 🎮 Your Game (Overview)

- **Players**: 2-4
- **Stages**: 3 (boss-ending)
- **Heroes**: 7 unique characters
- **Victory**: Hearts of the Boss, wealth, or class ability milestones
- **Core**: Asymmetric PvP/PvE, dice-based combat, equipment progression
