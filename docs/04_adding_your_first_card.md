```bash

```

### The Conversation

```

Question 1: What's the weapon's name?
> Frost Hammer

Question 2: How much should it cost?
> 7 gold

Question 3: How many weapon slots does it use? (1 or 2)
> 2 (it's a two-handed weapon)

Question 4: What attribute does it require to activate?
> Triangles

Question 5: How many triangles for base activation, and what's the effect?
```

## Step 2: Generated YAML

### What the Designer Creates

```yaml
# Frost Hammer - Rank 1 Two-Handed Weapon
# Auto-generated by @card-designer on 2025-10-10

name: Frost Hammer
rank: 1
category: weapon
hands: 2              # Uses both weapon slots
cost: 7
cost_type: gold

attributes:
  base:
    triangles: 1      # Need 1 triangle to activate
    effect: "+4"      # Base damage
  overcharge:
    triangles: 2      # Need 2 triangles for overcharge
    effect: "+7, target loses 1 armor permanently"

restrictions:
  - once_per_combat   # Must recharge after use

# Metadata
flavor_text: "The frozen malice of winter embodied in steel."
design_notes: "High-risk two-handed weapon with armor-shred mechanic"
balance_concerns: "Once-per-combat restriction compensates for high damage"
created_by: Pietro
created_date: 2025-10-10
```

### Understanding the Fields

**name**: Display name of the card
**rank**: Which stage it appears (1, 2, or 3)
**category**: weapon, armor, charm, or spell
**hands**: Weapon slots used (1 or 2)
**cost**: Purchase price
**cost_type**: gold or tokens

**attributes**:
- **base**: Minimum to activate + effect
- **overcharge**: Enhanced activation + stronger effect

**restrictions**: Special rules (e.g., once-per-combat, ranged-only)

**Metadata**: Design notes (not used by game engine, just for reference)

### The Designer Asks

```
@card-designer: Here's the card I created. Would you like to:

2. Make adjustments
3. See similar cards for comparison
```

### Balance Pre-Check

```
@balance-analyst: Analyzing Frost Hammer...

📊 Power Metrics:
  - Damage per gold: 1.00 DPG (rank 1 avg: 0.56)
  - Activation probability: 20% with 2 dice (triangle dependency)
  - Armor shred: High value (permanent effect)

⚖️ Balance Assessment:
  ⚠️ DPG is 78% above average
  ✅ Low activation probability balances power
  ✅ Once-per-combat restriction reduces abuse
  ⚠️ Two-handed opportunity cost is significant

💡 Recommendations:
  - Consider: Reduce cost to 6G (makes DPG ~1.17)
  - OR: Change to +3/+6 damage (reduces DPG to 0.86)
  - Current design is HIGH-RISK/HIGH-REWARD

Verdict: Powerful but fair given restrictions. Proceed?
```

### Your Decision

```
> The high DPG is intentional—it's a glass cannon weapon. Let's keep it.

@card-designer: Understood! I'll add a note about the intentional design.
Saving to rules/equipment/weapons_rank1.yaml...
```

## Step 7: Iteration

### Based on Simulation Feedback

```
> The high variance concerns me. Let's add a fallback effect.

@card-designer: Good idea! Here's a proposed change:

Current:
  attributes:
    base:
      triangles: 1
      effect: "+4"

New:
  attributes:
    fallback:
      triangles: 0      # When you roll NO triangles
      effect: "+1"      # Minimal effect
    base:
      triangles: 1
      effect: "+4"
    overcharge:
      triangles: 2
      effect: "+7, armor shred"

This way, the weapon always contributes something.

Apply this change?
> Yes

✅ Updated Frost Hammer
✅ Re-validating... ✅ VALID
🧪 Running quick simulation (10 games)...

New win rate vs. Orc Raider: 53% (was 48%)
Variance reduced: 48%-71% → 51%-68%

Better! Want to commit this version?
```
